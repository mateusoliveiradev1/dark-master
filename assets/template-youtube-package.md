## Checklist de publicação
- [ ] Título e thumb não repetem palavras.
- [ ] Capítulos válidos (00:00, ≥3, ≥10s, rótulos-resposta).
- [ ] Descrição: hook nos 150 chars + 2+ fontes + divulgação IA.
- [ ] ≤3 hashtags padronizadas.
- [ ] Vídeo relacionado (Related Video) ligado.
- [ ] Vídeo relacionado à série/playlist.
- [ ] Thumbs prontas para Test & Compare.
- [ ] Suspeitos vivos como "suspeito/acusado".
- [ ] Sem imagem gráfica na thumb/primeiros 15s.
- [ ] Publicar como não listado → 10–15 min → público.
- [ ] Feed de inscrições + notificações marcado.
