# Template — Thumbnail Brief

Para cada vídeo, produza um brief e **2–3 variantes** (mudar 1 eixo por vez).

```
VÍDEO: {{titulo}}
TÍTULO DIZ: {{contexto/número/termo de busca}}
THUMB DEVE MOSTRAR: {{objeto/resultado/emoção — o que o título NÃO diz}}

CONCEITO A (base)
- Ângulo: {{o que vende}}
- Sujeito focal: {{um só}}
- Texto (3–4 palavras): "{{...}}"
- Fundo/contraste: {{cor, rim light, escuro}}
- Composição: {{regra dos terços, olhar, crop}}
- Teste 120px: {{o que precisa ler}}

CONCEITO B (varia 1 eixo: {{ex.: rosto vs objeto}})
- ...

CONCEITO C (varia 1 eixo: {{ex.: texto vs sem texto}})
- ...

# Regras: 1 ponto focal · emoção/objeto legível · ≤4 palavras ≠ título
# contraste com a UI (yellow+black) · lê a 120px · SEM imagem gráfica
```
