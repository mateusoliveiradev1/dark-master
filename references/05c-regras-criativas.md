# 05c — Regras criativas (do PDF, Cap. 3)

Parafraseado do capítulo "Creative" e adaptado a canal dark solo. Estas regras decidem se o conteúdo é bom.

## A meta do conteúdo

- **Meta nº1:** fazer os **melhores vídeos de YouTube possíveis** — não os "melhor produzidos", não os "mais bonitos". O que importa é o que o YouTube/audiência quer.
- **Excitar quem cria.** No PDF, o vídeo só acontece se o criador estiver empolgado. Versão solo: se você não está curioso pelo caso, o viewer não estará.
- **Melhoria contínua**: ângulos, pacing, história, cor, som, thumb — sempre evoluindo por episódio.
- **Autenticidade**: nunca fingir. Não colocar ninguém (nem você) em situação de ter que mentir.

## Qualquer coisa vira conteúdo

- O PDF mostra um boneco de bebê virando infinitas ideias (arremesso, 1.000 bonecos, quebrar uma tábua). **Um mesmo tema tem infinitos ângulos.**
- **Regra de ouro:** **simples.** Para 50 milhões entenderem, tem que ser simples. "Me like simple."

## Formatos

- **Last to leave** — payoff no fim, vencedor desconhecido (retenção alta).
- **Stair stepping** — stakes crescem ($1 → $10 → … → recorde). Permite desviar desde que **escale**.
- **Chase/bounty** — resultado só no fim.
- **Abandonar formatos** é necessário. Todo canal que reusa formato por anos morre. **Não faça dois vídeos do mesmo formato seguidos.**
- **Dark:** formatos = "cold case desaparecimento", "assassino não identificado", "roubo/fraude", "cidade pequena". Rode séries, mas varie o ângulo; não repita a estrutura idêntica.

## Sucesso do conteúdo = AVD/AVP

- Vídeo com mais views tinha **+1:38 de AVD** no mesmo comprimento → **3× views**. AVD/AVP mandam.
- Front-load, transicione para uma história investida, sem momentos mortos, payoff satisfatório, **fim abrupto**.

## Quem é a audiência

- Defina o **viewer médio** de cada canal (no PDF: "adolescente memer que gosta de jogos"). Para dark 45+/TV: "adulto que quer calma e respeito, odeia gritaria e gore" (Cold File Diaries).
- Escreva para ele, não para "todos".

## Dieta de informação (dieta de inspiração)

- Você **não se inspira pelo que não sabe que existe.** Consuma coisas que melhorem seu roteiro (no PDF: Chris Tyson via cartoons → humor).
- **Dark:** consuma documentários, arquivos, podcasts de true crime, mapas, laudos — para ter repertório de ângulos e detalhes.

## Brand deals = conteúdo

- No PDF, brand deal lido em bloco gerava **cratera** na retenção; integrado à história, o dip é mínimo. Além disso, brand deals geram **residual** (re-spike quando você sobe vídeo novo).
- **Dark:** se um dia vender produto/patrocínio, integre ao caso (não leia em bloco). Ver `19`.

## Rapid-fire criativo (checklist)

- [ ] Sem **dull moments** (corte tudo que não move a história).
- [ ] **Fim abrupto** (protege retenção; não sinalize o fim).
- [ ] **Não finja intensidade** — se não é intenso, não force.
- [ ] **50/50?** Se um trecho tem 50% de chance de funcionar, **escreva outro melhor**.
- [ ] **Rode o conteúdo em várias pessoas** antes de fechar.
- [ ] **Nunca minta** (nem em situações que exijam "atuação").
- [ ] Se um imprevisto aconteceu nas imagens/produção, **vire conteúdo**.
- [ ] Estude os **últimos ~50 vídeos** do seu nicho antes de roteirizar.
- [ ] Defina **um momento "wow"** que só o seu canal faria (ver `05`).

## Fontes proibidas / cuidados
- Nunca apresentar teoria como fato; sem gore; respeitar vítimas (ver `09`).
