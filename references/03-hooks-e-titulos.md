# 03 — Hooks e títulos (Y1–Y11)

Destilado de `sergebulaev/youtube-skills` (MIT — ver `vendors/ATTRIBUTION.md`).

O hook no YouTube é **duplo**: a **embalagem** (título + thumb) ganha o clique; a **abertura** (30s no long-form, 3s no Short) ganha o watch time. Um título que ganha o clique e perde a abertura é **negativo** (fast click-away é penalidade).

## Títulos (packaging → CTR)

**Y1 — Curiosity-Gap**
```
{resultado surpreendente}. Here is what nobody tells you.
Why {coisa comum} {falha / funciona ao contrário do que você pensa}
```

**Y2 — Number / Listicle**
```
{N} {coisas} que {payoff específico} (number {X} {surpreendeu})
```
> Cuidado: listicle puro raramente é outlier. Número funciona melhor com claim de dinheiro/tempo.

**Y3 — How-I Outcome**
```
How I {resultado com número} in {tempo} (no ads / with a free tool)
```
> Versão mais forte: valor **não redondo** + tempo curto + ferramenta nomeada ("How I Make $24,937/mo…").

**Y4 — Mistake / Negativity**
```
Stop {ação}. You are {losing / wasting / killing} {coisa específica}.
```
> Forte em gear/tutorial; **ausente** em business/creator. Não é over-performer universal.

**Y5 — Transformation / Before-After**
```
I {fiz algo difícil} for {tempo}. Here is what changed.
```

**Y6 — Versus / Comparison**
```
{Opção A} vs {Opção B}: {quem ganha / a surpresa}
```
> Niche-dependente (gear/software). Zero em business no corpus.

**Y11 — Third-Party Success Story** (o formato mais frequente em long-form no corpus)
```
How {pessoa/arquetipo} Built {número grande} From {Zero} | {Untold} Story
```

## Aberturas (retention)

**Y7 — Restate-and-Raise (30s)**
```
{linha que entrega a promessa do título, na sua voz}
{linha que aumenta a aposta / nomeia o obstáculo}
By the end you will {capacidade concreta}
```

**Y8 — Cold-Open Payoff Tease (30s)**
```
{abre com o pico/resultado, 3–8s}
{Corta pro setup} But to get here I had to {obstáculo}.. let me show you.
```

**Y9 — Question-and-Contract (30s)**
```
{a pergunta exata que o título implicou}
Short answer: {resposta real e parcial}. But the part that matters is {a coisa profunda}.
Stick around.. by the end you will also {bônus}.
```

**Y10 — Shorts 3-Second Hook**
```
{uma linha falada ou texto na tela que entrega payoff/tensão no frame 1}
```
Ex.: "this one setting doubled my views and it is off by default".

## Tabela de pareamento

| Título | Pareie com | Por quê |
|---|---|---|
| Y1 | Y7 | confirma o gap e o amplia |
| Y2 | Y9 | promete a lista + bônus |
| Y3 | Y8 | mostra o resultado, depois os passos |
| Y4 | Y7 | nomeia o custo, depois o conserto |
| Y5 | Y8 | mostra o "depois", volta pro "antes" |
| Y6 | Y9 | responde "quem ganha" rápido, depois a nuance |
| Y11 | Y8 | mostra o resultado, depois como chegou |
| Qualquer Short | Y10 | o título importa menos; o frame 1 é tudo |

## Micro-regras de hook [PRATICANTE]

- Título e thumb **nunca repetem** as mesmas palavras.
- **"How I" > "How to"** (resultado vivido carrega prova).
- Front-load: mobile corta ~60 chars; palavras decisivas no começo.
- **Abra no meio da ação**; nunca com saudação.
- **Um número específico** no título/1ª linha ("em 28 dias" > "rápido").
- Mediana de hook: 11 palavras (Short) vs 12 (long-form) — a diferença é **compressão**, não "linguagem diferente".

## Nunca

- Prometer além do que os primeiros 30s entregam.
- Intro/logo antes do hook.
- Keyword-stuffing no título.
- ALL CAPS/emoji para forjar intensidade.
- Escrever título e thumb isolados um do outro.
