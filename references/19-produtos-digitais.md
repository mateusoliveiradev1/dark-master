# 19 — Produtos digitais (receita fora do AdSense)

Como transformar audiência em receita além de anúncios. Base: vídeo-fonte "First $7 digital product" + pesquisa 2026. [ALEGADO/PRATICANTE]

## Princípio central

O primeiro produto barato **não é para ganhar dinheiro — é para criar um comprador**. Comprador de item barato é **5–12x** mais provável de comprar o próximo (caro) do que um lead grátis. O **comprador é o ativo**.

## A "$500 Rule"

Qualquer produto digital **abaixo de $500** vende (e é entregue) sem:
- ligação de venda,
- ligação de coaching,
- precisar de aprovação do cônjuge.

Isso elimina a fricção de confiança/fechamento. Ideal para começar.

## Os 3 critérios de oferta (Dan Henry)

1. **Tangível, não intangível** — entregue algo concreto e usável já (template, planilha, swipe file, slide deck). O comprador não precisa "acreditar em você".
2. **Promessa pequena, não transformação** — prometa resolver 1 problema específico bem. Fácil de entregar, fácil de confiar.
3. **Trend + tricky** — tema na moda, mas difícil para a média (ex.: usar uma ferramenta de IA). O gap entre hype e competência é o que vende.

## Estrutura de preço (tripwire)

| Preço | Conversão típica | Uso |
|---|---|---|
| $7 | 4–8% | audiência fria, listas novas |
| $17 | 3–6% | sweet spot geral |
| $27 | 2–4% | audiência morna |
| $37–47 | 1–2% | tráfego pago qualificado |

Regra: o tripwire ≈ **10–15x mais barato** que a oferta principal.

## Stack de monetização (eleva o ticket)

- **Order bump** — checkbox no checkout (ex.: +um pack de templates). +15–25% no AOV.
- **Upsells** (2–3 após a compra) — dobram/triplicam a receita do mesmo número de compradores.
- **Core offer** ($97–497+) — via página ou sequência de e-mails (5–7 dias).
- **Funil de e-mail** — lead magnet → tripwire → core → recorrente.

## Passo a passo (do vídeo-fonte)

1. Escolher nicho (pode usar IA para pesquisar nichos/problemas).
2. **Escolher UM problema específico** (não "dicas de X" genérico).
3. Criar o entregável (PDF + checklist + áudio = bundle).
4. **Mockups** (o que o comprador recebe, visualmente).
5. Página de vendas simples (mockup + título + botão de compra).
6. Tráfego: **pago** (rápido, ex.: Meta/TikTok) ou **orgânico** (lento, mas constrói confiança).
7. Iterar: subir preço, melhorar produto.

## Conectando com o canal dark

- Shorts/long-form = topo de funil (atenção).
- Descrição/comment pinado = CTA para o tripwire.
- E-mail = canal próprio (independe do algoritmo).
- Nichos dark com bom fit de produto: história/mistério (packs de pesquisa, mapas, timelines), true crime (guias, templates), finanças criminais (planilhas, checklists).

## Warnings

- **Não** faça produto barato e vazio: precisa "valer mais que o preço".
- Orgânico é lento — não espere vendas na 1ª semana.
- Produto é fácil; **conseguir clientes é a parte difícil**.
- Cuidado com claims de renda (políticas + ética).

## Checklist de produto digital
- [ ] Um problema específico escolhido.
- [ ] Entregável tangível pronto.
- [ ] Mockup + página de vendas.
- [ ] Order bump + ≥1 upsell.
- [ ] Sequência de e-mail.
- [ ] CTA no canal (descrição/pin).
- [ ] Preço testado ($7–27 para começar).
