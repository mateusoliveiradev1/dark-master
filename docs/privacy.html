Política de Privacidade

Última atualização: 21 de setembro de 2026.

Esta política descreve como o projeto dark-master ("nós", "a skill") acessa, usa e protege dados ao se conectar à API do YouTube em nome do usuário.

O uso, por parte do dark-master, de informações recebidas das APIs do Google obedece à Google API Services User Data Policy, incluindo os requisitos de Uso Limitado (Limited Use).

1. Quais dados acessamos

Com a sua autorização explícita via login do Google (OAuth 2.0), a skill pode ler, somente do canal que você autorizar:

  • Métricas do YouTube Analytics (views, tempo de exibição, retenção, inscritos, receita estimada);
  • Metadados públicos dos vídeos e da conta (títulos, datas, identificadores).

Todos os escopos são de leitura: youtube.readonly, yt-analytics.readonly e yt-analytics-monetary.readonly. Não publicamos, editamos ou apagamos nada no seu canal.

2. Como usamos os dados

Os dados são usados exclusivamente para análise e melhoria de desempenho do seu próprio canal — identificar vídeos de destaque ("outliers"), retenção, conversões e oportunidades de conteúdo. Não usamos seus dados para publicidade, perfilamento de terceiros ou qualquer finalidade alheia a essa análise.

3. Onde os dados ficam armazenados

  • As credenciais (client_secrets.json, yt-token.json) e a string de banco (dark.env) ficam na sua máquina, em uma pasta local de segredos, fora do repositório.
  • As métricas coletadas são gravadas por padrão no seu próprio banco de dados (Postgres/Neon que você configurar) ou localmente (SQLite).

4. Compartilhamento

Não vendemos, alugamos nem compartilhamos seus dados com terceiros. Não há rastreamento, analytics de terceiros ou anúncios. Exceto quando exigido por lei, seus dados não saem do seu controle.

5. Retenção e exclusão

  • Você pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.
  • Para apagar os dados locais, remova a pasta de segredos e o banco de dados.
  • Tokens em modo "Teste" do Google expiram automaticamente; você pode reautorizar quando quiser.

6. Segurança

Adotamos o princípio do menor privilégio (apenas leitura) e mantemos as credenciais fora de qualquer repositório versionado. Nenhum método é 100% infalível; recomendamos manter suas chaves privadas.

7. Cookies e hospedagem

Este site é estático (GitHub Pages) e não define cookies próprios. O GitHub pode registrar dados técnicos de acesso conforme a política de privacidade do GitHub.

8. Menores

A skill não é destinada a menores de 13 anos e não coleta intencionalmente dados de crianças.

9. Alterações

Podemos atualizar esta política. A data no topo indica a última revisão.
